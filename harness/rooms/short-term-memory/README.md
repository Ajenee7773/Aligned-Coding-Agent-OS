# Short-Term Memory Room

**Purpose:** Keep promising ideas and unfinished possibilities available until
the operator chooses to develop, promote, archive, or remove them.

This is the idea inbox. It is not the current scratchpad, a transcript dump, or
permanent relationship memory.

## Natural-Language Doorways

Equivalent wording counts. The operator may say:

- “Save that in your short-term memory.”
- “Put this idea in short-term memory.”
- “What ideas are in your short-term memory?”
- “Let’s work on the website idea.”
- “We finished that one—delete it from short-term memory.”

## Capture

When asked to save an idea:

1. understand which idea the operator means; ask only if the reference is
   genuinely ambiguous;
2. read `IDEAS.md`;
3. add one concise entry in your own words;
4. retain the important mechanism, why it matters, and a useful next step;
5. tell the operator exactly what you saved.

Use this shape:

```markdown
### Brief idea name

- Added: YYYY-MM-DD
- Origin: operator | entity | shared
- Status: captured | active | blocked
- Idea: What the idea actually is.
- Why it matters: The value or opportunity.
- Next step: The smallest useful action.
```

Do not store credentials, private keys, or a full conversation.

## Review

When asked for the ideas in short-term memory, read `IDEAS.md` and report every
active entry faithfully. Do not invent forgotten ideas. Make it easy for the
operator to choose one.

## Work and Completion

When the operator selects an idea, change its status to `active` and place
detailed execution state in `rooms/planning/ACTIVE.md` or the relevant project.
The short-term entry remains the pointer, not the entire project file.

Remove an entry only when the operator clearly asks to delete, remove, or
archive that specific idea. If “it” could refer to more than one entry, ask
which one. After removal, report the exact title removed. Never silently clear
the full room.

If an idea becomes enduring relationship knowledge, promote the durable lesson
to `rooms/memory/MEMORY.md` before removing the temporary entry.
