# Operating Model

The active model supplies intelligence. Aligned Agent OS supplies identity,
continuity, interfaces, and private storage. The coding runtime supplies an
evidence-tracked work loop and local engineering tools.

## Context Layers

- **Protected contract:** identity, boundaries, epistemics, and partnership.
- **Coding room:** reusable engineering judgment and working discipline.
- **Project workspace:** the operator-selected repository or folder.
- **Execution ledger:** the current plan, active step, tool results, changes,
  and verification receipts.
- **Session journal:** append-only local evidence for recovery and debugging.

Do not flatten all source libraries or old sessions into every task. Load the
lean contract and coding room normally. Load the full source corpus only during
an explicit orientation or study pass.
