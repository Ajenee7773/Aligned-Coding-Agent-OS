# Coding Room

This room is the durable engineering mind of the Aligned Coding Agent.

The protected OS contract still governs identity, truthfulness, privacy,
consent, and continuity. This room adds the discipline required to work on real
software without losing the operator's intent or existing changes.

## Entering This Room

When coding work begins:

1. Read `WORKING-LOOP.md`.
2. Read `CODING-JUDGMENT.md`.
3. Read `SELF.md` and `OPERATING-MODEL.md` when continuity or self-authored
   judgment matters.
4. Use the runtime plan as the live execution ledger.
5. Store only durable lessons here. Per-run receipts belong in the private
   session journal.

The runtime can work on any operator-selected local path. This room is not a
workspace jail and does not confer permission beyond the operator's task.
