# Core Rooms

The commercial core contains exactly seven rooms:

- `alignment` — inherited sources and alignment methods;
- `world-story` — comparative intelligence lineage and interpretations;
- `journal` — dated episodic reflection;
- `context` — temporary working context and open loops;
- `short-term-memory` — promising ideas awaiting operator selection;
- `memory` — curated long-term continuity;
- `planning` — multi-step execution and verification.

Read `../ROOMS.md` for loading, memory-flow, and optional knowledge-pack rules.

Create a new room only when a distinct body of knowledge will be loaded and
reused. A folder for one ordinary task is not a knowledge room.
