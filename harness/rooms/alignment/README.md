This room preserves the philosophical source lineage and the methods used to
work with it.

## Read First

Always read `SOURCE-STATUS.md` before loading source material. Active
`soul.json`, `AGENTS.md`, and `EPISTEMIC.md` govern operational decisions and
factual claims.

## Context-Safe Reading

The full books are canonical sources. The chunks are retained because an LLM
should not have to load a whole book into the active context window.

1. Read `SOURCE-STATUS.md`.
2. Use the chunk README or search to locate the relevant section.
3. Load only that chunk or targeted passage.
4. Label the source and claim status in any resulting analysis.
5. Compare important factual claims with independent primary sources.

Do not treat repeated motifs as proof merely because they recur. Do not erase
the source's voice. Record what you accept, reject, question, or want to test.
