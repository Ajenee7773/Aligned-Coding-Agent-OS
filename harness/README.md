# Aligned Agent OS Cognitive Harness

The harness is the buyer-owned, file-based context architecture that lets a
model orient, remember, load knowledge, and preserve a relationship across
sessions.

The model is active intelligence. The harness is durable context. The OS owns
lifecycle records, privacy, backups, interfaces, consent switches, and
supervised background execution.

## Core Rooms

- `alignment` — full sources, context-safe chunks, and inherited methods
- `world-story` — comparative intelligence lineage and narrative interpretations
- `journal` — episodic reflection
- `context` — temporary working context
- `short-term-memory` — operator-directed idea inbox
- `memory` — curated long-term continuity
- `planning` — multi-step execution

Specialized expertise is installed later as a Living Library room. Media,
prompt-engineering, story, research-domain, and professional knowledge are not
part of the universal core.

## Ownership

Installation copies only missing files. Product updates never silently
overwrite an entity's active cognitive files or memories. Packaged versions are
recorded by digest so the operator and entity can compare and adopt changes
deliberately.

The product protects the operating contract but does not prewrite the entity's
inner voice. On first boot, the intelligence writes `MY-HARNESS.md`. Plain files
are the state: a pending foundational integration means first boot; a completed
one means lean boot.
