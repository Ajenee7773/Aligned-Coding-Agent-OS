# Aligned Coding Agent OS — Quick Start

You do not need Git or manual configuration for normal Windows setup.

## 1. Install

Install Node.js 22 or newer, extract the release ZIP, and double-click:

```text
install.bat
```

The installer creates a separate private runtime at:

```text
%USERPROFILE%\.aligned-coding-agent-os
```

## 2. Introduce the entity

Enter your name, the entity's name, and your shared mission. Then connect a
local model or enter a provider key. Credentials remain outside the Cognitive
Harness.

Approve the model introduction or succession choice. A different model is
never silently presented as the previous entity.

## 3. Let it orient

The first awakening reads the inherited foundation in resumable stages and
writes a small personal harness. Later starts use **Continue** to recover that
small External Brain. **Foundations** deliberately rereads the complete source
library and is not required for ordinary starts.

## 4. Choose a project

Open **Code** in the left navigation. Press **Choose workspace**, paste or
select the absolute path of an existing project folder, and confirm it.

The readiness panel shows the active model, endpoint, workspace, Coding Room,
and private session location. The selected project may be anywhere the
operator can access; the Coding Edition does not copy it into a sandbox.

## 5. Assign work

Describe the outcome in normal language and press **Run task**. The workbench
shows:

- the agent's step-by-step plan;
- the single active step;
- file and command activity;
- coordination requests that need your decision;
- changed files and verification evidence.

Press **Stop** to cancel an active run. For deep reorientation, enable
**Full coding orientation** before starting a task.

## Normal operation

Use **Chat** for the ongoing relationship and **Code** for engineering work.
Both use the same private entity, model connection, Cognitive Harness, and
rooms. Coding-run journals are stored under:

```text
%USERPROFILE%\.aligned-coding-agent-os\data\sessions\coding
```

To launch later, double-click:

```text
%USERPROFILE%\.aligned-coding-agent-os\Start Aligned Coding Agent OS.bat
```

Terminal users can run:

```text
start.bat --terminal
```

Optional Telegram setup remains disabled until deliberately paired. Run
`telegram-setup.bat`, enter the BotFather token in the hidden local prompt, and
confirm the matching one-time pairing code locally.

Use **System → Create safe backup** to preserve the harness, lineage,
conversations, and runtime data. Credentials are excluded by default.
