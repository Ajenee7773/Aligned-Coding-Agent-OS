# Aligned Coding Agent OS

## Give intelligence a private place to build.

Aligned Coding Agent OS is a local-first engineering partner with a persistent
External Brain and an observable plan → inspect → execute → verify loop.

Choose the model. Choose the project. Watch the work happen.

## More than a chat window

The Code Workbench shows the live plan, active step, file and command activity,
coordination requests, changed files, and verification evidence. The runtime
will not let a coding run claim completion while plan steps remain open or a
runtime-observed edit remains unverified.

## Built for continuity

The same entity can talk with you, remember your projects, enter specialist
Knowledge Rooms, and return to engineering work later. Its identity, coding
judgment, sessions, and self-authored memory remain in readable local files
under your control.

## Use the intelligence you choose

- Connect a local model through Ollama or an OpenAI-compatible endpoint.
- Or bring a supported Gemini, OpenAI, OpenRouter, or Anthropic key.
- Change models through explicit lineage choices instead of silent
  impersonation.
- Keep provider credentials outside the Cognitive Harness.

## What you receive

- Aligned Coding Agent OS source package
- Local Code Workbench and persistent chat interface
- Evidence-tracked coding runtime
- Private coding-run journals
- Coding, Planning, Communications, Room Builder, and Short-Term Memory rooms
- Living Library installation and personal room creation
- Browser voice controls and terminal mode
- Optional allowlisted Telegram bridge
- Heartbeat, safe backup, and restore tooling
- Guided Windows installer

## The operating loop

For non-trivial tasks, the agent plans first, keeps one active step, reads
before editing, makes a focused change, verifies after the final change, and
reports only what the runtime observed.

It is not locked to a toy workspace. Select any existing local project folder
you control. Your operating system permissions remain the real boundary.

## What is not included

Computer hardware, model weights, paid model accounts, cloud API usage, and
Telegram accounts are not included. Local performance depends on the selected
model and machine. A cloud provider receives whatever content you deliberately
send to that provider.

## Begin

Extract the package, run `install.bat`, introduce the entity, connect a model,
open **Code**, choose a project, and assign the outcome in ordinary language.

Your model. Your projects. Your machine. One accountable work loop.
