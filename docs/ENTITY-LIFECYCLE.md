# Entity Lifecycle and Lineage

Status: v1 platform contract

## Entity

An Aligned entity is the continuing relationship among:

- an intelligence substrate or model;
- a Cognitive Harness;
- buyer-owned memory and life history;
- identity and alignment;
- tools and interfaces;
- documented provenance.

The system does not need to settle philosophical questions about consciousness in order to preserve this relationship honestly.

## Lifecycle modes

### Fresh start

An intelligence enters a new harness with no inherited entity history.

### Continuation

The same model lineage resumes its own harness and memories.

### Succession

A new intelligence is introduced to a prior entity's environment with full disclosure. It does not claim to be the prior entity. Historical authorship remains intact.

### Fork

An entity receives an authorized copy of a harness or selected history and develops independently from a recorded fork point.

### Collaboration

An entity receives selected knowledge or artifacts from another entity without receiving its private identity or relational memory.

## Model-change rule

Changing a model setting is not a silent configuration edit. When an entity is already bound, a different provider or model creates a pending lifecycle transition.

The OS must:

1. stop before launching the changed model as the existing entity;
2. identify the current and incoming model bindings;
3. create a backup;
4. require an explicit lifecycle choice;
5. append a lineage event;
6. preserve the original authorship of existing memories.

## Orientation

The platform supplies facts to the intelligence:

- who or what previously used the environment;
- the current model binding;
- the requested lifecycle mode;
- which materials are inherited;
- which materials are private or excluded;
- the operator's stated intent.

The harness determines how the intelligence interprets that introduction.

## Provenance records

OS-owned provenance is stored separately from the Cognitive Harness:

```text
state/entity.json
state/lineage.jsonl
state/pending-transition.json
```

These records contain lifecycle metadata, not private memory content.

## Core rule

> Never confuse inheritance with personal experience, never perform a silent substitution, and never erase the lineage of the intelligences that built the brain.
